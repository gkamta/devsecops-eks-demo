# Security Policy

This is a portfolio/reference repository. It contains **no real credentials,
account IDs, or classified/CUI data**; account IDs such as `123456789012` and
hostnames under `example.mil` are placeholders.

The local Keycloak realm (`keycloak/realm-export.json`) ships demo users with
documented passwords for `docker compose` use only. Never import it into a
shared or production Keycloak.

To report a vulnerability, open a private security advisory on the repository.
